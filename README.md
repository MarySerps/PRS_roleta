# 🎡 Roleta de Prêmios - PRS Reformas

Uma aplicação web interativa de roleta da sorte desenvolvida para eventos e otimizada para exibição em telas gigantes (como TVs de 86"). Os participantes giram a roleta para concorrer a brindes e mimos exclusivos da PRS Reformas em uma experiência gamificada.

---

## ✨ Funcionalidades

* **Renderização Dinâmica:** A roleta é desenhada matematicamente em tempo real utilizando a API `Canvas` do HTML5.
* **Design Responsivo Extremo:** Layout construído utilizando CSS moderno (`vh`, `vw` e `clamp()`), garantindo proporção perfeita e impedindo que a aplicação quebre ou corte em televisores 4K ou telas com muito zoom.
* **Experiência Audiovisual:** Efeitos sonoros programados para o momento do giro, vitória e derrota, além de uma música de ambiente integrada para os momentos de espera.
* **Física e Animações:** Animação de giro com desaceleração realista (fórmula matemática de *Ease-Out*) e pop-ups animados de resultado.
* **Sistema de Auto-Reset:** Temporizador inteligente que exibe o resultado por 7 segundos e reinicia a tela automaticamente para o próximo jogador.
* **Modo Totem:** Preparada para rodar em *Modo Quiosque* (Tela cheia), escondendo abas e controles do navegador.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica.
* **CSS3:** Variáveis nativas, Flexbox para alinhamento e Keyframes para animações de interface.
* **JavaScript (Vanilla):** Manipulação de DOM, cálculos de trigonometria para o Canvas API, controle de estado e manipulação da Audio API (sem uso de frameworks externos).
